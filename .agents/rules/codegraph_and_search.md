# Rule: CodeGraph & Efficient Search Guidelines

- **CodeGraph First**: Selalu utamakan penggunaan CodeGraph (`codegraph_explore` atau `codegraph explore`) sebelum melakukan `grep`/`find` atau membaca file jika repositori terindeks (`.codegraph/`).
- **Efisiensi Search & Tool**: Hemat dan efisien dalam penggunaan `grep`/`find` (dapat memanfaatkan `rtk` / pencarian terarah) untuk mencegah output berlebih.
- **Kelengkapan Jawaban**: Efisiensi pemanggilan tool/pencarian tidak boleh membatasi detail, kelengkapan, dan kualitas jawaban/analisis yang disampaikan kepada pengguna.
